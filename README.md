# 🍔 Кампус Фуд (Campus Food)

**Кампус Фуд** — веб-приложение и Android-клиент для предзаказа еды из столовой колледжа к перемене с доставкой в аудиторию и поддержкой студенческой программы лояльности.

---

## ✨ Основной функционал

* **Каталог блюд и фильтрация:** разбивка по категориям (*Выпечка*, *Горячее*, *Напитки*), живой поиск по названию и описанию, бейджи хитов и веса порций.
* **Адаптивный интерфейс (Desktop + Mobile):**
  * На десктопе — двухколоночный макет с быстрым правым сайдбаром «Твой заказ» для мгновенного оформления.
  * На мобильных устройствах — нижняя панель навигации, плавающая кнопка корзины и пошаговое оформление.
* **Студенческий бонусный кошелёк:** баланс **500 баллов** («Электронный студенческий») с возможностью списать до **30%** от суммы заказа и справкой по начислению баллов в сервисах колледжа (Задачник, Бронь Кабинки, Хакатон Хаб, ИТ.Спорт, Медиацентр).
* **Оформление доставки:** выбор учебного корпуса, номера аудитории и времени готовности к перемене.
* **Живой трекинг и автостатусы заказа:** 4 этапа выполнения (*Принят* → *Готовится* → *Курьер в пути* → *Доставлен*) с автоматическим продвижением статуса каждую минуту на основе времени создания заказа.
* **Локальное хранилище (IndexedDB) + JSON:** корзина, баланс и история заказов сохраняются локально в IndexedDB и не сбрасываются после перезапуска приложения. Поддерживается экспорт и импорт базы заказов в файл `orders_db.json`.

## 🗃 Модель данных

В приложении используются следующие логические сущности (хранятся в `IndexedDB` в хранилищах `orders` и `state`):

* **Product** (`id`, `name`, `category`, `desc`, `weight`, `badge`, `price`, `emoji`) — позиция меню.
* **CartItem** (`productId`, `quantity`) — товары в текущей корзине.
* **Order** (`id`, `items`, `subtotal`, `bonusSpent`, `cardPaid`, `building`, `room`, `delivery`, `status`, `createdAt`) — оформленный заказ.

## 🚀 Запуск и сборка

### 1. Запуск веб-версии в браузере
Откройте файл `index.html` из корня проекта в любом современном браузере.  
> **Примечание:** для корректной автозагрузки `orders_db.json` через `fetch` рекомендуется запускать через локальный веб-сервер (например, расширение **Live Server** в VS Code или `python -m http.server`).

### 2. Сборка Android APK (Android 8.0+)
1. Установите **Android Studio** и **Android SDK Platform 34**.
2. Откройте папку `CampusFood` как проект в Android Studio и дождитесь завершения **Gradle Sync**.
3. В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

* **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, CSS Variables), Vanilla JavaScript (ES5/ES6)
* **Storage:** Browser IndexedDB API, FileReader / Blob API (JSON export/import)
* **Mobile:** Android SDK (Java, `WebView` с включённым `DOMStorage` и `JavaScript`)
